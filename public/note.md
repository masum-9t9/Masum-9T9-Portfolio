## 💡 Quick Start Guide

### 1. Install Dependencies
```bash
npm install
```

### 2. Environment Configuration
Create a `.env` file using `.env.example` as a reference.

### 3. Launch Development Server
```bash
npm run dev
```

### 4. Build for Production
```bash
npm run build
```
