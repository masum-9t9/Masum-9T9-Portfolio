💡 QUICK START GUIDE
--------------------------------------------------------------------
1. Run "npm install" to install all required dependencies.
2. Create a ".env" file using ".env.example" as a reference.
3. Launch the local dev environment with "npm run dev".
4. Build for production using "npm run build".
