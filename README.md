## 🌟 Newly Implemented Innovations

The portfolio now integrates these cutting-edge visual and functional modules:

### 1. 🌋 `LiquidEmberMotionBackground` (Procedural Canvas Engine)
- **Fluid Wave Currents**: Multi-harmonic trigonometric liquid current equations creating continuous organic movement beneath the hero fold.
- **60 FPS Molten Embers**: Interactive canvas simulation rendering floating, swaying sparks with authentic luminous flicker (`#FF7A18`, `#FF9238`, `#FFA053`).
- **Video Ready**: Built-in support for 10-second cinematic video loops via the `videoSrc` prop with smooth fallbacks.

### 2. ⚡ `SectionDivider` (Luminous Amber Boundary)
- **1px Opacity Gradient**: Seamless horizontal line fading from 0% on the margins to 50% amber in the center (`from-transparent via-[#FF7A18]/50 to-transparent`).
- **Diffused Ambient Glow**: Layered soft ambient backlight (`via-[#FF7A18]/25 blur-md`) paired with a luminous center filament (`via-[#FFA053]/85`) for visual hierarchy between **About**, **Services**, **Projects**, **Reviews**, and **Contact**.

### 3. 🎡 `Review3DCarousel` & `InfiniteReviewMarquee`
- **3D Cylindrical Perspective Carousel**: High-impact spatial testimonial viewer supporting interactive touch gestures, drag rotation, and instant rating badges.
- **Continuous Velocity Marquee**: Auto-scrolling horizontal marquee for verified client ratings and endorsements.

### 4. 🧮 `ProjectCalculator` (Dynamic Budget & Turnaround Estimator)
- **Interactive Scope Builder**: Clients can dynamically toggle services (Thumbnail, Banner, UI/UX, Full Website), select urgency, and calculate estimated turnaround times and investment budgets with instant social checkout triggers.

### 5. 🧭 Clean Path SPA Routing & History Sync
- **Modern Clean URLs**: Direct browser history synchronization for `/about`, `/services`, `/projects`, `/reviews`, and `/contact` with complete backward compatibility for legacy hash navigation.

### 6. 🌐 Dual-Language Localization (English & বাংলা)
- Instant stateful toggle adapting copy, localized numbers, Bengali typography (`Hind Siliguri`), and English display types (`Evantic` / `Manrope`).

## ⚡ Getting Started & Installation

### Prerequisites
- **Node.js**: `v18.0.0` or later
- **npm**: `v9.0.0` or later (or `pnpm` / `bun`)

### 1. Clone Repository
```bash
git clone https://github.com/masum-9t9/masum-9t9-portfolio.git
cd masum-9t9-portfolio
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Environment Configuration
Create a `.env` file in the root directory:
```bash
cp .env.example .env
```
Populate the configuration:
```env
APP_URL=https://9t9.pro.bd
BREVO_API_KEY=your_brevo_api_key_here
FROM_EMAIL=hello@9t9.pro.bd
FROM_NAME="Masum 9T9"
TELEGRAM_BOT_TOKEN=your_bot_token_here
TELEGRAM_CHAT_ID=your_chat_id_here
```

### 4. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 5. Build for Production
```bash
npm run build
npm start
```
